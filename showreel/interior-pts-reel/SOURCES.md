# Source Inventory

## Rights Boundary

These public links are evidence and private-edit source references. A public
portfolio reel re-hosts edited excerpts and is not equivalent to embedding the
original uploads. Before deployment, confirm that portfolio excerpt use is
acceptable and replace any uncertain source music with a cleared track.

Source clips belong in `assets/source-clips/`, which is excluded from Git.
Do not commit browser cookies, downloaded metadata containing personal data, or
full source programs.
