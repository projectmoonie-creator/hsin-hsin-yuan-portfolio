# Interior Card Reel

Silent moving thumbnail for the Interior / Spatial Brand Films card.

- Duration: 14 seconds
- Canvas: 1280 x 720
- Frame rate: 30 fps
- Credit represented by the surrounding site card: Director / Editor
- Source audio: removed
- Website output: `public/assets/showreel/interior-spatial-card-reel.mp4`

Run `scripts/make-selects.sh`, then `npm run check` and `npm run render`.
Working source clips, selects, renders, and snapshots are excluded from Git.
