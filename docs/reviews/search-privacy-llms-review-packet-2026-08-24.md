## Exact implementation behavior

- The build loads that file, generates `/en/privacy/index.html` and `/zh/privacy/index.html`, and writes root `/llms.txt`.
- Each Privacy page has its own canonical URL plus `en`, `zh-Hant`, and `x-default` alternates. It contains no script tag, forms, trackers, cookies, video, or animation.
- Existing Contact links still open externally in a new tab; the new internal Privacy link stays in the same tab.
- The sitemap now contains exactly four canonical locations: `/en/`, `/zh/`, `/en/privacy/`, and `/zh/privacy/`. Home pages cross-alternate only with each other; Privacy pages cross-alternate only with each other.
- Privacy pages reuse the existing site header, design tokens, typefaces, focus styling, and responsive breakpoint. The desktop section layout is two columns; at 820px and below it becomes one column.
- The root page and existing homepage rendering are otherwise unchanged.
