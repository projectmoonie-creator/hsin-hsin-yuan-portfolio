## Current LinkedIn constraints

- The account is free, not Premium.
- Standard profile sections include About, Position/Experience, Education,
  Skills, Featured, Projects, Services, Recommendations, Languages, and other
  optional sections.
- LinkedIn's official help says profile information including Headline, About,
  Experience, Education, Skills, and location contributes to job matching and
  recommendations.
- Featured can contain external links and work samples, but Featured content is
  not itself discoverable through search and requires viewers to be logged in.
- Any member can create a Service Page for free. Premium adds richer showcase
  features; it is not required for the basic service list.
- Open to Work can be shared with recruiters only or all members. Recruiter
  search uses target job types and preferred locations, but employer privacy
  safeguards are not absolute.
- Newly added Projects no longer have a dedicated Project URL field; a link is
  added through media.
